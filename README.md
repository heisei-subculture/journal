# 平成サブカル通信

J-POP、モー娘。、バトロワ、M-1。新しいニュースも昔の良記事も、好きなものを軸に集めるカルチャー帖。

公開先リポジトリ: https://github.com/heisei-subculture/journal

予定する公開URL: https://heisei-subculture.github.io/journal/

## このMacで使う

「起動.command」を開き、表示されたURLへアクセスします。Python 3.10以上が必要です。追加パッケージやAPIキーは不要です。

```sh
python3 pipeline/serve.py
```

- 読む: http://127.0.0.1:8765/
- 書く: http://127.0.0.1:8765/editor.html
- 終了: ターミナルで Control+C

閲覧だけなら `site/index.html` を直接開いても動きます。編集室の保存には上のサーバーが必要です。

## 投稿する

編集室で「新しいつぶやき」を書いて保存します。ニュースへのコメントは下の投稿一覧から対象を選びます。
保存先は `data/posts.json`。AIの要約と本人コメントは別に保持します。編集後は通信ページを再読み込みしてください。
「あとで読む」はブラウザ内の保存です。端末間同期はありません。

## 毎朝のキュレーション

朝7時、日本時間。新旧合わせて最大5件。AIが探す・読む・選ぶ・要約する部分は、このチャットのCodex定期タスクで行います。
詳細は `pipeline/CURATION.md`。RSS収集は動作確認済みのナタリー4分野を入口にし、過去記事はWeb検索でも発掘します。
自動タスクの実行時は、このMacの電源が入り、アプリが起動している必要があります。APIキーによる別の有料サービス連携は組み込んでいません。Codex側の利用枠は消費します。
定期タスクの作成状態は、このチャットの最終報告を参照してください。コードだけで定期実行は開始しません。

新着を義務にせず、古い記事は「再発見」と元記事の日付を表示。過去イベントの告知を現在の開催情報として扱いません。
本人のコメント・つぶやきはAIが勝手に作りません。

## GitHubへ公開するとき

1. このフォルダのコードを `heisei-subculture/journal` の `main` にpush。
2. リポジトリの Settings → Pages → Source を GitHub Actions にする。
3. Actions → Publish journal を実行し、成功を確認。

公開は `dist/` の5ファイルと `.nojekyll` のみ。編集室・バックアップはサイトに配置しません。
リポジトリ自体はPublicのため、コミットしたソース・投稿内容は誰でも閲覧できます。秘密情報をコミットしないでください。
現在の自動タスクはローカル更新のみです。公開運用に切り替える場合は定期タスクの指示にもpush工程を追加します。
